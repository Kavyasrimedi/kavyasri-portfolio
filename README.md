# Kavyasri Portfolio

This project contains the structure for a personal portfolio website.

## Folders

- `css/` for styling
- `js/` for JavaScript
- `assets/images/` for profile and project screenshots
- `assets/icons/` for favicons and icons
- `assets/cv/` for resume PDF

## Notes

- Add your real profile photo to `assets/images/profile.jpg`
- Add your project screenshots to the corresponding files
- Add your resume PDF to `assets/cv/kavyasri_resume.pdf`
- Replace favicon with your actual brand icon
